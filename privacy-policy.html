Privacy Policy

CSS Inspector Pro Chrome Extension

Last Updated: July 24, 2026

Thank you for using CSS Inspector Pro. Your privacy is important to us. This Privacy Policy explains how our Chrome extension handles information.

1. Information We Collect

CSS Inspector Pro does not collect, store, transmit, or sell any personal information.

✔ No personal information collected
✔ No browsing history collected
✔ No website content stored
✔ No analytics used
✔ No advertising trackers
✔ No third-party data sharing

2. How the Extension Works

CSS Inspector Pro operates entirely inside your browser.

  • Inspects HTML elements.
  • Displays CSS properties.
  • Reads computed styles locally.
  • Does not send webpage information anywhere.

3. Permissions

The extension requests only the permissions necessary to provide its functionality.

  • activeTab – Inspect the current page after user interaction.
  • scripting – Inject the inspector into the active webpage.
  • storage – Save user preferences such as inspector state.
  • Host Permissions – Required to inspect webpage elements selected by the user.

4. Remote Code

CSS Inspector Pro does not download or execute remote code. All HTML, CSS and JavaScript files are packaged inside the extension.

5. Third-Party Services

This extension does not use:

  • Google Analytics
  • Advertising Services
  • Tracking Pixels
  • External APIs
  • Cloud Databases

6. Data Sharing

We do not sell, rent, share, transfer, or disclose any user data because the extension does not collect user data.

7. Children's Privacy

CSS Inspector Pro is not directed toward children under 13 years of age and does not knowingly collect information from children.
